# FitPlus — interface text pack
Use this English (India) copy as the default. Keep strings centralised for future Hindi and Marathi translations. Dynamic values use named placeholders. Use sentence case for labels and headings. Avoid body-shaming, medical guarantees and unnecessary exclamation marks. All coach names, pricing and activity data in Stage 1 are fictional.

## Generic states and accessibility
Loading: Getting things ready… | Error: Something didn't load. Please try again. | Offline-like demo: Changes saved on this device for this demo. | Retry: Try again | Unsaved: Discard your changes? | Cancel: Keep editing | Save: Save changes | Reset: Resetting removes all local demo progress. | Success: Changes saved. | Accessibility labels: Open streak details; Open notifications; Close dialog; View day {date}; {percent}% complete; Select {name}; Remove {name} from selection. Do not use icon-only actions without accessible names.
